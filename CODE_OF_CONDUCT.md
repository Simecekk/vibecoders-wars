# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient — many players are making their very first pull request. No harassment, insults or spam. Don't game the votes.

Report problems to the maintainer, @Simecekk (GitHub). The maintainer may hide comments, label PRs `vv:blocked`, remove points or areas, or ban accounts.
